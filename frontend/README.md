# B-SIDE 프런트엔드

React·TypeScript·Vite로 만든 B-SIDE 웹 클라이언트입니다. 개발 서버는 `/api`와 `/socket.io` 요청을 기본 백엔드(`http://localhost:3001`)로 전달합니다.

```powershell
npm install
npm run dev
```

검증은 `npm run lint`, `npm run build`, `npm test`로 실행합니다. 코드 구조와 작업 규칙은 [AGENTS.md](./AGENTS.md), 전체 실행·배포 방법은 [운영 가이드](../docs/OPERATIONS.md)를 참고하세요.
